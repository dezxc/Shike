# 拾刻 Shike

> 拾起这一刻，先做五分钟。

拾刻是一款运行在 macOS 上的低心智专注工具。它不试图成为复杂的任务管理器，而是帮助你在难以开始时，以尽可能低的心理门槛重新进入工作。

## 当前版本（0.9.13）

这是一个可以本地构建和使用的 macOS 原生应用。当前已经包含：

- arm64 与 x86_64 通用二进制，可运行于 Apple Silicon 和 Intel Mac。
- 高级首次启动引导，明确说明五分钟启动、自由定时、状态栏操作与本地隐私规则。
- 通知权限不再无说明地弹出；设置页会显示“权限正常、尚未授权或系统已关闭”，并提供对应处理入口。
- 应用菜单提供使用引导、品牌化关于窗口和本地数据目录入口。
- 默认主窗口缩小为 900×640；开始前采用“倒计时 + 本轮设置”双栏布局，开始后自动收起设置与统计，只留下任务、倒计时和必要控制。
- 任务空状态提供可立即执行的写法示例，不再只展示大面积空表格。
- 状态栏项目启动后会主动保持可见；再次双击 App 时优先打开状态栏操作面板。
- 轻量任务列表：圆形完成标记、任务名和摘要严格沿同一中线排布；当前任务使用明亮白色聚焦面、细强调色描边和左侧短线，完成任务使用绿色对勾与删除线，两种状态不再混淆；支持创建、编辑、完成、删除、排序、置顶和选择当前任务。
- 完整任务详情：预计番茄、标签、备注、提醒、每天/每周/每月重复规则和子任务。
- 任务提醒会注册为原生 macOS 通知；完成或删除任务后自动取消。
- 25 分钟标准番茄。
- 超过 3 小时未有效专注时的 5 分钟启动；结束时同样播放提醒、显示系统通知并弹出日志页。
- `5 分钟 → 填写日志 → 自动休息 1 分钟 → 询问是否开始下一轮`。
- 1～180 分钟的单次自定义时长，休息结束或放弃后恢复默认专注时长。
- 15、20、25、30 分钟快捷选择。
- “专注到……”：指定结束时刻，按真正开始时的时间自动计算本轮分钟数。
- 暂停、继续、提前结束。
- 所有自然完成的番茄都会先填写日志，日志窗口关闭后自动启动休息倒计时。
- 普通休息按专注时长的 1/5 计算：25 分钟休息 5 分钟、5 分钟休息 1 分钟；达到设定轮次后进入长休息。
- 休息到点后一定先提醒并询问，只有用户确认才会开始下一轮专注。
- 使用绝对结束时间的可靠倒计时。
- App 退出或崩溃后的计时状态恢复。
- 本地系统通知和可选提醒音。
- 每轮番茄完成后立即弹出日志页，默认只问“这一刻，你完成了什么？”，详细记录按需展开；提前结束时还可补充中断原因。
- 今日番茄数与实际专注时间。
- 按时间排列的专注历史。
- 支持按今天、本周、已完成和提前结束筛选历史，并编辑完成日志或中断原因。
- 任务和专注记录采用可恢复删除，可在应用内回收站恢复或二次确认后永久删除。
- 独立的真实专注日历窗口，支持日、周、月视图和前后周期导航；点击日历中的专注记录即可查看并编辑本轮日志。
- 独立日历窗口采用参考图与 macOS 日历式双栏结构：左侧为可直接选择日期的迷你月历，右侧为日、周、月时间轴；迷你月历支持前后翻月、有记录日期圆点、系统蓝选中态以及所选日期统计。累计达到一小时后，侧栏会同时保留总分钟数并显示“折合 X 小时 X 分钟”。
- 日/周视图保留清晰的星期日期表头、周数、全天栏和低对比度小时/日期网格，以 72px 每小时覆盖完整 07:00～24:00，可上下滚动查看，并正确拆分跨午夜的专注记录。
- 专注记录使用参考图式浅青宽卡片和更清晰的字号；同一时间或视觉范围内相邻的短记录会自动横向分栏，极密集记录也不会互相覆盖或越过日期列。卡片直接呈现完成摘要，并在空间允许时补充起止时间、时长和具体日志。
- 启动后默认驻留菜单栏，不主动弹出主窗口；状态栏以统一的 14pt Semibold“计时器图标 + `mm:ss`”持续显示剩余时间，并记住用户按住 `⌘` 拖动后的位置。
- 点击状态栏即可使用独立操作面板：选择 15/20/25/30 分钟、开始、暂停、继续、结束、打开主窗口、日历和设置；点击面板外部会自动收起。
- 支持 `⌘⇧M` 快速打开状态栏操作面板。
- 新增圆环式专注进度视觉和原创 macOS App 图标；图标主体按 92% 光学缩放并保留透明安全边距，使 Dock 中的视觉大小与其他应用更协调。
- 统一的品牌头部、内容卡片、任务空状态和记录统计卡片。
- 可配置默认专注、长休息、长休息间隔、系统通知和中断原因。
- 支持登录 Mac 后自动启动（应用需位于“应用程序”文件夹）。
- 任务列表会直接展示置顶、预计番茄、子任务进度和标签摘要。
- 按比例短休息、长休息和长休息间隔的数据模型。
- 完全本地的 JSON 数据存储。

0.9.13 完善日历侧栏的累计时长表达：保留“175 分钟”这类精确总分钟数，并在下一行补充“折合 2 小时 55 分钟”；不足一小时不重复展示，整小时和带余分钟的边界均有自动化测试覆盖。既有任务页、专注流程和数据规则保持不变。正式公开下载仍需使用发布者自己的 Apple Developer ID 完成签名与公证。

## 构建

系统要求：

- macOS 13 或更高版本（Apple Silicon 或 Intel）。
- Apple Command Line Tools，或完整 Xcode。

```bash
make
```

构建完成后，应用位于：

```text
build/Shike.app
```

运行：

```bash
make run
```

运行核心逻辑与应用流程测试：

```bash
make test
```

完整测试矩阵和隔离 UI 验收方式见 [`TESTING.md`](TESTING.md)。

从图标母版重新生成 `.icns`：

```bash
make icon
```

生成对外分发压缩包：

```bash
make release
```

默认会生成临时签名的本地测试包。正式对外发布时可提供 Developer ID 和公证配置：

```bash
DEVELOPER_ID_APPLICATION="Developer ID Application: 你的名称 (TEAMID)" \
NOTARY_PROFILE="notary-profile" \
make release
```

产物位于 `dist/`，同时生成 SHA-256 校验文件。正式公开下载必须完成 Developer ID 签名和 Apple 公证。

`make release` 会同时生成：

- `Shike-版本-macOS.dmg`：推荐提供给普通用户，打开后把“拾刻”拖入“应用程序”。
- `Shike-版本-macOS.zip`：便于自动化分发和归档。
- 两个产物各自对应的 `.sha256` 校验文件。

设置 `DEVELOPER_ID_APPLICATION` 与 `NOTARY_PROFILE` 后，发布脚本会签名 App 和 DMG，分别完成 Apple 公证并装订公证票据。

## 安装

1. 双击打开 DMG 安装盘。
2. 把 `Shike.app` 拖到同一窗口中的“Applications”文件夹。
3. 从“应用程序”启动拾刻；之后它会默认驻留在顶部状态栏。

## 状态栏使用

拾刻启动后会首先出现在 macOS 顶部状态栏。即使主窗口关闭，计时和状态栏入口也会继续工作。

- 点击“计时器图标 + 剩余时间”打开快捷面板。
- 准备状态可直接选择本轮分钟数并开始。
- 专注中可直接暂停、继续或提前结束。
- 在“设置 → 状态栏与启动”中控制倒计时和 Dock 图标显示。
- 若菜单栏项目较多，拾刻会使用自适应紧凑宽度，尽量避免被系统折叠。

## 数据位置

所有任务、专注记录和设置都保存在本机：

```text
~/Library/Application Support/Shike/data.json
```

删除任务不会删除历史专注记录；记录会保留开始专注时的任务名称快照。

## 计数规则

| 专注类型 | 计番茄 | 计专注时间 |
|---|---:|---:|
| 完成 25 分钟 | 1 | 是 |
| 完成单次临时番茄 | 1 | 是 |
| 系统 5 分钟启动 | 0 | 是 |
| 提前结束 | 0 | 是 |
| 暂停时间 | 0 | 否 |

## 技术说明

当前版本使用原生 AppKit 和 Objective-C 实现，可以只依赖 Apple Command Line Tools 构建。核心计时与数据逻辑独立于界面并包含自动化测试。后续如果迁移到 SwiftUI，现有产品规则、数据格式与测试场景仍可继续复用。
